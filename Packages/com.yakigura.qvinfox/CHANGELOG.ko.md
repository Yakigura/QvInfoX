# 변경 이력

## 1.0.0

2026-11-09

- 플레이어별 진행률과 전체 완료 예상 시간을 표시하는 QvPen 동기화 모니터를 출시했습니다.
- 자동 설정에서 저장한 계층 구조 순서대로 펜별 상세 정보를 표시합니다.
- QvHold는 VR에서 펜 유지를 전환하며, 데스크톱에서는 항상 펜을 유지합니다.
- 핸들로 패널을 이동하고 일본어, 영어, 한국어를 전환하며 모니터에서 패키지 버전을 확인할 수 있습니다.
- 새 모니터를 스폰 지점 근처 바닥 위에 배치하고 기본적으로 10초마다 자동 새로고침하며 Tools 메뉴를 추가·갱신 및 제거 중심으로 정리했습니다.
